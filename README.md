# Tim Huang profile — GitHub Pages

Upload the contents of this folder to the root of your GitHub Pages repository (or a subfolder if using a project site). `index.html` is the entry point.

## Profile photo
The source Google Sites image could not be packaged automatically. Replace the portrait placeholder in `index.html` with your preferred local image. For example, put `profile.webp` in this folder and replace the `.portrait` contents with `<img src="profile.webp" alt="Dr. Tim Huang, DSW, LCSW-S">`, then add `.portrait img{width:100%;height:100%;object-fit:cover;border-radius:inherit}` to `style.css`.
